# 📁 Pasta de Informes de Rendimentos (Segura & Ignorada pelo Git)

Esta pasta foi criada para que você possa salvar temporariamente seus informes de rendimentos, extratos de corretoras, notas de corretagem ou comprovantes de despesas médicas/educação para a IA analisar.

---

## 🔒 Garantia de Privacidade

> [!IMPORTANT]
> **Esta pasta está no `.gitignore`!**
> 
> Todo o conteúdo desta pasta (com exceção deste arquivo `README.md`) é **ignorado pelo Git**. Isso significa que:
> - Qualquer PDF, planilha (XLSX), imagem (PNG/JPG) ou arquivo de texto contendo dados confidenciais (CPF, salários, saldos bancários) que você colocar aqui **NUNCA** será enviado para o seu GitHub público.
> - Seus dados permanecem locais na sua máquina de forma 100% segura.

---

## 🛠️ Como Usar com o Assistente

1. **Adicione os Arquivos:** Copie os arquivos de informe de rendimentos (fornecidos pelo seu empregador, bancos, corretoras, convênio médico, etc.) para dentro desta pasta (`informes/`).
2. **Peça a Análise no Chat:** Peça para o assistente ler os arquivos. Exemplos de comandos:
   - *"Analise todos os informes que salvei na pasta de informes"*
   - *"Leia o informe da Corretora X que está na pasta de informes e me diga o que preencher"*
   - *"Extraia os dados do informe do Banco Y e me diga os códigos exatos"*
3. **Preenchimento:** O assistente analisará os arquivos e fornecerá a lista de fichas, códigos e valores a declarar.
4. **Limpeza (Opcional):** Após preencher sua declaração, por medida adicional de segurança, você pode deletar os arquivos fiscais desta pasta.
